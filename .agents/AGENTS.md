# Typography Rules

1. **No Bold Body Text**: In this project, never use bold styling (`font-bold`, `font-semibold`, `font-medium`, `<b>`, `<strong>`) for body text or paragraph text. 
2. **Headings Only**: Boldness should strictly be reserved for headings (`<h1>`, `<h2>`, `<h3>`, etc.) and subheadings. All normal text should remain normal weight (`font-normal`).
